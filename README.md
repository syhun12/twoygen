# TWOYGEN Website Frontend

투와이젠 기업 홈페이지 리뉴얼을 위한 **UI/프론트엔드 프로토타입**입니다.

## 구현 범위

- Next.js App Router 기반 반응형 프론트엔드
- 메인 / 회사소개 / 사업분야 / 제품소개 / 기술력 / 납품실적 / 고객지원 화면
- 기획서의 다크 네이비·딥 블루·에너지 그린 디자인 시스템 반영
- 제품 상세, 프로젝트 상세, 공지·자료실·문의 UI 포함
- 백엔드, DB, 그누보드 CMS, 실제 문의 전송 기능은 포함하지 않음

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 권장 Node.js

Node.js 20 LTS 권장 (최소 18.17 이상)
